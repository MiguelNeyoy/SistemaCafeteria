# Dtos (Application)
Objetos de transferencia de datos entre capas (UI / Casos de Uso).

## Subcarpetas:
- `Catalogo/`: DTOs para CRUD y listados de Categorías, Productos y Extras.
- `Ventas/`: DTOs para ítems, apertura de cuenta, cobro y resumen detallado de ventas.
- `Comandas/`: DTOs para ítems e instrucciones enviadas a cocina.
- `Tickets/`: DTOs con datos del comprobante físico emitido.
- `Reportes/`: DTOs para cortes de caja diario y mensual con cálculo de arqueo.
- `Seguridad/`: DTOs para cambio de PIN de administrador.
